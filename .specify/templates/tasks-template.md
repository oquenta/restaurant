# Plantilla de tareas — La Paila

Tareas agrupadas por fases, con casilla para [Spec-Kit /spec-kit] encontrar al hacer:

- [ ] 1.2 …
  - [ ] 1.2.1 sub-tarea
  - [ ] 1.2.2 …

Cada tarea enlaza a su historia de usuario ([US-1], [US-2]…) y, cuando aporta, al archivo con marcadores:
`src/lib/negocio.ts` / `contracts/menu.json` etc.

## Convención
- Tarea del cliente → marca [US-n].
- Tarea del cajero → [CP-n]. Núm. de tarea 3.x son de gerencia [AP-n].
- Bloques paralelizados van marcados [P].
